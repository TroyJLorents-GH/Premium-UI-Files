# Research source ledger

Research date: **November 6, 2026 · America/Phoenix**.

Companion to [Premium UI/UX Field Guide](PREMIUM-UI-UX-FIELD-GUIDE.md).

V means official documentation, a repository, or an explicitly identified official catalog was inspected for the stated capability. R means the individual source was not substantively inspected in this pass. Inspection is not installation, benchmarking, an independent license review, or proof of ongoing maintenance. Recommendations about fit are editorial judgments. Retrieval may use indexed/cached page content and does not establish a millisecond-live state.

The guide deduplicates eight overlapping rows across research areas. Original research IDs remain stable, so gaps are intentional. Source-ledger entries for consolidated rows remain as provenance. There is no claim to have reviewed every release, dependency, or GitHub issue.

## Motion and graphics source ledger

Research date: **2026-11-06, America/Phoenix**. Sources were read through web retrieval. No packages were installed and no comparative performance benchmark was run. Primary docs/repositories are used for functionality; practical fit/tradeoffs are the researcher's recommendations.

### GSAP

- [GSAP core](https://gsap.com/docs/v3/GSAP/): tween/timeline core and utility/lifecycle API inventory.
- [GSAP official plugin catalog](https://gsap.com/docs/v3/Plugins/): confirms plugin families and dependency notes. Catalog-verified rows are explicitly labeled `V, catalog`; their linked individual detail pages were not all separately fetched.
- [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/): scrub, pin, snap, scroll configuration.
- [ScrollSmoother](https://gsap.com/docs/v3/Plugins/ScrollSmoother/): native scrolling plus transformed content; dependency on ScrollTrigger; touch configuration.
- [SplitText](https://gsap.com/docs/v3/Plugins/SplitText/): line/word/character splitting, responsive re-splitting, ARIA assistance, nested accessibility considerations.
- [Flip](https://gsap.com/docs/v3/Plugins/Flip/): measured layout transitions, interruption handling, framework lifecycle considerations.
- [Draggable](https://gsap.com/docs/v3/Plugins/Draggable/): drag/rotate/bounds and Inertia integration.
- [MorphSVG](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/): SVG path morphing.
- [DrawSVG](https://gsap.com/docs/v3/Plugins/DrawSVGPlugin/): stroke-reveal behavior; does not animate fill.
- [React integration](https://gsap.com/resources/React/): `useGSAP` and cleanup integration.
- [Current custom GSAP standard no-charge license](https://gsap.com/community/standard-license/): explicitly includes prohibited visual-animation-builder uses; the document avoids equating no-charge licensing with MIT.

### Native platform motion and rendering

- [MDN Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API): animation interfaces, control, accessibility, reduced-motion guidance.
- [MDN View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API): same-document and cross-document transitions and related features.

- [MDN OffscreenCanvas](https://developer.mozilla.org/en-US/docs/Web/API/OffscreenCanvas): canvas rendering/worker use.

### Scope and verification notes

- 88 catalog entries; includes browser APIs, plugins, packages, authoring products, and distinct ecosystem capabilities. This is not 88 independent animation libraries.
- 72 entries are verified against a retrieved official page or official catalog; 16 are reference-only (`R`). Catalog-only evidence is labeled explicitly.
- Current capability verification does not establish maintenance velocity, a security audit, accessibility compliance, or fastest performance.
- No GitHub trending ranks or star-growth claims are asserted. GitHub star numbers visible in fetched pages were deliberately not used as quality evidence.
- Requests to an older Three.js manual path and the tsParticles homepage failed; Three.js was verified through current official documentation, while tsParticles remains `R` with its repository supplied for follow-up.
- No independent source was used to declare a library deprecated. Older/niche choices carry recheck notes rather than unsupported deprecation claims.
- Motion patterns and timing suggestions are original practical recommendations. They are not an exhaustive taxonomy or universal timing standard.
