07 // GSAP SCROLLTRIGGER PIN, TIMELINE LABELS & SNAP

Pinned Set Piece: One Request, Four Chapters

The stage pins for 300% of viewport travel while one labeled timeline moves four actors together: the packet, the stage nodes, the chapter copy and the progress rail. Tweens inside are linear; scrub: 0.8 supplies the easing and snap: "labels" lands the scroll on the nearest chapter.

Reduced motion: unpinned, all chapters readable
LABEL ingress
PROGRESS 0%
01 // Ingress

The packet arrives at the edge.

TLS terminates, the request is stamped with a trace id, and the edge decides which region owns it. Nothing has been computed yet; everything can still be refused cheaply.

02 // Auth

Identity is checked once, then carried.

The token is verified against the key set and exchanged for a short-lived claim. Downstream services read the claim instead of calling the identity provider again.

03 // Compute

Work happens close to the data.

The handler runs in the region that holds the row. Reads come from the replica, writes go to the primary, and the trace records both durations separately.

04 // Egress

The response leaves with its receipt.

Headers carry the trace id and the server timing of every stage you just scrolled through, so the same request can be replayed from the browser's network panel.

Nav 10A + 10B // Direction-aware header & section progress

Hide on Scroll Down, Reveal on Scroll Up

ScrollTrigger.create({ scroller, start: 0, end: "max" }) reports direction and progress; the header moves on yPercent only and returns the moment keyboard focus enters it. Each section has its own trigger for the rail.

Intro

Scroll down and the header leaves; scroll up by any amount and it returns. The rule is direction, not distance, so a reader who pauses never loses the navigation.

11 // DRAWSVG, MORPHSVG & MOTIONPATH IN ONE SCROLL-DRIVEN SCENE

A Route Is Drawn, A Courier Follows, A Parcel Arrives

Three plugins, one story, one scrubbed timeline. drawSVG draws the route by true length, motionPath carries the courier along it with autoRotate, and morphSVG turns the box into a parcel at the hub and into a seal at the door. Labels arrive after about 75% of the travel.

Reduced motion: the delivered frame, unpinned
SCENE drawing
01 // Draw the route

The plan appears before anything moves.

DrawSVG measures the path and reveals it by length, so a longer route takes the same scroll but draws faster. No dash constants to break when the path changes.

02 // Carry it

The courier follows the line it was given.

MotionPath samples the same path by distance and rotates the courier into the curve. At the hub the box becomes a parcel: MorphSVG tweens the path data itself.

03 // Hand it over

Delivered, sealed, labelled.

The parcel morphs once more into a seal and pulses. Only now do the place names fade in: annotate after the movement has settled, never during it.
